# Employee Burnout Prediction

An ML-based project for predicting employee burnout using workplace, personal, and well-being related factors.

## 📌 About the Project

This project explores the use of Machine Learning to identify patterns and indicators associated with employee burnout.

The dataset contains employee-related features such as working hours, stress level, sleep hours, work pressure, job satisfaction, manager support, work-life balance, and other workplace factors.

The project includes data analysis, feature engineering, model development, and a prediction demo.

📊 Dataset
The project uses an employee burnout dataset containing 2,000 records and 30 features.
The dataset is used for educational and machine learning experimentation purposes.
